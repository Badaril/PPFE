**Naturalis** est une expérience VR immersive centrée sur l’exploration de la faune nocturne de la région PACA. Le joueur incarne un naturaliste chargé de recenser différentes espèces animales en les photographiant afin de compléter son carnet d’observation.

Lien de la page itch.io du projet : https://badaril.itch.io/naturalis
